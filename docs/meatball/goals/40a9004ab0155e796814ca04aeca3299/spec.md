**All** shows every task, **Active** shows incomplete tasks, and **Completed** shows completed tasks. Every view shows the total number of incomplete tasks across the full list and an empty message when no tasks match. Adding, completing, reopening, or deleting a task immediately refreshes the visible rows and count. Reload restores saved tasks and completion states, with the filter allowed to reset to **All**. Clicking **Add** or pressing **Enter** still adds exactly one task per valid submission, and the calculator remains reachable.

With a completed task stored before an incomplete task, **Completed** shows one row and an incomplete count of one. Completing the only row in **Active** shows the empty message and a count of zero. A near miss is removing the first visible row in **Active** and deleting the hidden completed task because the row's filtered position was used as its stored position.
